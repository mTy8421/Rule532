# เครื่องคิดเลขแบ่งเงินเดือน 50/30/20

เว็บภาษาไทยสำหรับคำนวณการแบ่งเงินเดือนหรือรายรับเป็น 3 ส่วนตามสัดส่วน 50/30/20 พัฒนาด้วย HTML, CSS และ JavaScript เปิดใช้งานในเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งแพ็กเกจหรือรันเซิร์ฟเวอร์

## ความสามารถ

- คำนวณผลลัพธ์ทันทีเมื่อเปลี่ยนจำนวนรายรับ
- แบ่งรายรับเป็นค่าใช้จ่ายจำเป็น 50% ความต้องการส่วนตัว 30% และเงินออมและลงทุน 20%
- แสดงจำนวนเงินเป็นบาท พร้อมตัวคั่นหลักพันและทศนิยมสูงสุด 2 ตำแหน่ง
- ปรับรูปแบบการแสดงผลให้เหมาะกับหน้าจอคอมพิวเตอร์และมือถือ
- คำนวณในเบราว์เซอร์ ไม่มีการส่งรายรับไปยังเซิร์ฟเวอร์หรือบันทึกข้อมูลถาวร

## วิธีใช้งาน

1. ดาวน์โหลดไฟล์โปรเจกต์ โดยเก็บ `index.html`, `style.css` และ `script.js` ไว้ในโฟลเดอร์เดียวกัน
2. เปิด `index.html` ด้วยเว็บเบราว์เซอร์ที่เปิดใช้งาน JavaScript
3. กรอกจำนวนเงินในช่อง **เงินเดือนหรือรายรับทั้งหมด** หน่วยเป็นบาท
4. ดูยอดเงินทั้ง 3 หมวดและยอดรวม ซึ่งจะอัปเดตอัตโนมัติโดยไม่ต้องกดปุ่ม

ค่าเริ่มต้นคือ **5,000 บาท** โดยแสดงผลดังนี้:

| หมวด | สัดส่วน | จำนวนเงิน |
| --- | --- | --- |
| ค่าใช้จ่ายจำเป็น | 50% | 2,500 บาท |
| ความต้องการส่วนตัว | 30% | 1,500 บาท |
| เงินออมและลงทุน | 20% | 1,000 บาท |
| **รวม** | **100%** | **5,000 บาท** |

หากช่องกรอกว่างหรือกรอกค่าติดลบ ระบบจะใช้ 0 ในการคำนวณ เมื่อโหลดหน้าใหม่ รายรับจะกลับเป็นค่าเริ่มต้น

## โครงสร้างไฟล์

```text
cal/
├── index.html   # โครงสร้างหน้าเว็บ ช่องกรอกรายรับ และส่วนแสดงผล
├── style.css    # สี รูปแบบ และการจัดวางสำหรับหน้าจอขนาดต่าง ๆ
├── script.js    # การคำนวณสัดส่วนและอัปเดตจำนวนเงิน
└── README.md    # คำอธิบายโปรเจกต์และวิธีใช้งาน
```

## การปรับแต่ง

- แก้ข้อความและค่าเริ่มต้นของช่องกรอกใน `index.html`
- แก้สี ฟอนต์ และการจัดวางใน `style.css`
- แก้สูตรคำนวณในฟังก์ชัน `updateResults()` ใน `script.js` หากเปลี่ยนสัดส่วน ให้ปรับข้อความเปอร์เซ็นต์และยอดเงินเริ่มต้นใน `index.html` ให้ตรงกันด้วย

จำนวนเงินแต่ละหมวดแสดงทศนิยมสูงสุด 2 ตำแหน่ง ผลรวมของตัวเลขที่แสดงจึงอาจต่างจากรายรับเล็กน้อยจากการปัดเศษ
